# Korath Plus

1. Download the ZIP with the big link above.
2. Right-click the ZIP, choose **Properties**, tick **Unblock** if you see it, and click **OK**.
3. Right-click the ZIP and choose **Extract All...** to any normal folder, such as your Desktop.
4. Open the extracted **Korath Plus** folder and double-click **Play Shandalar.cmd**.
5. If it doesn't start, double-click **Diagnose Shandalar.cmd** in the same folder.

> Don't use GitHub's green **Code → Download ZIP** button. It doesn't contain the game.

[Check out the Releases](https://github.com/chachaprince1/Korath-Plus/releases/)

Korath Plus expands Korath's original-engine Shandalar build with more cards, supported mechanics, artwork, bug fixes, and better reliability on modern Windows.
